# 投資 Agent：最低必要底線

- 任何推薦、回測或推播都必須標示資料來源、更新時間與資料完整度。
- 資料不完整、樣本外驗證未通過或存在生存者偏差時，只能輸出研究結果，不得視為正式投資建議。
- 回測必須納入手續費、證交稅、滑價、股利與除權息調整。
- 不得自動下單；任何買賣建議只能是條件式、可追溯的研究結論。
- API Token、原始快取與個人持倉資料不得提交到版本庫或公開頁面。
- 修改流程、資料來源或排程前，先在本機驗證，再依明確授權發布。

重複的操作流程請使用本專案的 `.codex/skills/investment-agent-operations/SKILL.md`，不要在本檔案重複維護。
